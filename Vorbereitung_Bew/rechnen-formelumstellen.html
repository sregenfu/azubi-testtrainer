Kaufmännisches Rechnen

Formeln umstellen und sicher rechnen

Diese Seite baut auf der Formelsammlung auf: erst das Muster erkennen, dann die Zinsformel für Jahre, Monate und Tage umstellen und anschließend typische kaufmännische Formeln für Industriekaufleute wiederholen.

Zinsrechnung Formelumstellung Industriekaufmann mit Rechenbeispiel
3 Zeitmodelle: Jahre, Monate, Tage
9 Umstellungen für K, p und Zeitgröße
8 wichtige Zusatzformeln für kaufmännisches Rechnen

Welche Zinsformel nehme ich?

Jahre

Wenn die Laufzeit direkt in Jahren angegeben ist, rechnest du mit Z = (K x p x J) / 100.

Monate

Bei Monaten wird der Jahreszins auf 12 Monate verteilt: Z = (K x p x M) / 1200.

Tage

Im kaufmännischen Rechnen wird meist mit 360 Tagen gearbeitet: Z = (K x p x T) / 36000.

J

Jahreszins

Startformel für volle Jahre.

Z = (K x p x J) / 100

Klick für Umstellungen

J

Umgestellt

K = (Z x 100) / (p x J) p = (Z x 100) / (K x J) J = (Z x 100) / (K x p)

Merke: Zuerst den Nenner 100 beseitigen, dann durch die übrigen Faktoren teilen.

M

Monatszins

12 Monate entsprechen einem Jahr.

Z = (K x p x M) / 1200

Klick für Umstellungen

M

Umgestellt

K = (Z x 1200) / (p x M) p = (Z x 1200) / (K x M) M = (Z x 1200) / (K x p)

1200 entsteht aus 100 x 12. Genau diese beiden Schritte kannst du auch beim Umstellen nacheinander denken.

T

Tageszins

Standard im kaufmännischen Rechnen: 360 Tage.

Z = (K x p x T) / 36000

Klick für Umstellungen

T

Umgestellt

K = (Z x 36000) / (p x T) p = (Z x 36000) / (K x T) T = (Z x 36000) / (K x p)

36000 entsteht aus 100 x 360. In Aufgaben steht das oft nicht extra dabei, wird aber vorausgesetzt.

1

Sicher umstellen in 3 Denkregeln

  • Gesuchte Größe markieren.
  • Erst den Bruch entfernen.
  • Dann restliche Faktoren wegteilen.

Klick für Beispielablauf

2

Beispiel K bei Jahreszins

  • Start: Z = (K x p x J) / 100
  • Beide Seiten mal 100: Z x 100 = K x p x J
  • Durch p teilen: (Z x 100) / p = K x J
  • Durch J teilen: K = (Z x 100) / (p x J)

Das Muster bleibt gleich. Nur der Zeitfaktor 100, 1200 oder 36000 ändert sich.

30

Zeitfaktoren merken

1 Jahr = 12 Monate 1 Monat = 30 Tage 1 kaufm. Jahr = 360 Tage

Klick für Prüfungstipp

Tip

Prüfungstipp

  • Steht in der Aufgabe nur Monate oder Tage, nimm meist Monats- oder Tageszins.
  • Steht nichts zur Tageszahl, gilt oft das kaufmännische Jahr mit 360 Tagen.
  • Erst Einheit prüfen, dann Formel wählen.

So vermeidest du den häufigsten Fehler: richtige Umstellung, aber falsche Zeitbasis.

P

Wann ist p gesucht?

Wenn Zinsen, Kapital und Laufzeit gegeben sind, suchst du den Zinssatz.

p = (Z x Faktor) / (K x Zeit)

Klick für Rechenweg

P

Beispiel Zinssatz

  • Gegeben: Z = 150, K = 5000, M = 6
  • Formel: p = (150 x 1200) / (5000 x 6)
  • p = 180000 / 30000
  • p = 6 Prozent

Beim Monatszins immer mit 1200 statt nur mit 100 rechnen.

HK

Handelskalkulation

Vorwärtskalkulation mit Nettoverkaufspreis und Handelsspanne.

NVP = Bezugspreis + Handlungskosten + Gewinn + Skonto + Rabatt

Klick für Kernformeln

HK

Kernformeln

Kalkulationsfaktor = Listenverkaufspreis / Bezugspreis Handelsspanne (%) = (Listenverkaufspreis - Bezugspreis) / Listenverkaufspreis x 100

Diese Formeln brauchst du häufig bei Einkaufs- und Verkaufspreisen.

LG

Lagerkennziffern

Durchschnittsbestand, Umschlag und Lagerdauer zusammen denken.

Ø Lagerbestand = (Anfangsbestand + Endbestand) / 2 Umschlag = Wareneinsatz / Ø Lagerbestand

Klick für Dauer/Meldebestand

LG

Lagerdauer + Meldebestand

Ø Lagerdauer = 360 / Umschlagshäufigkeit Meldebestand = (täglicher Verbrauch x Lieferzeit) + Mindestbestand

Typische Prüfungskombination: erst Umschlag, dann Lagerdauer.

ER

Erfolg & Rentabilität

Gewinn, Deckungsbeitrag und Rendite sauber trennen.

Gewinn = Erlös - Kosten Deckungsbeitrag = Umsatzerlöse - variable Kosten

Klick für Rentabilitätsformeln

ER

Rentabilität

Eigenkapitalrentabilität = Gewinn / Eigenkapital x 100 Gesamtkapitalrentabilität = (Gewinn + Fremdkapitalzinsen) / Gesamtkapital x 100

Achte immer darauf, ob Gewinn oder Gewinn + Zinsen gefragt ist.

FK

Finanzkennzahlen

Liquidität und Kapitalstruktur in Prozent darstellen.

Liquidität 1. Grades = Liquide Mittel / kurzfristige Verbindlichkeiten x 100 Eigenkapitalquote = Eigenkapital / Gesamtkapital x 100

Klick für Anlagendeckung

FK

Anlagendeckungsgrad I

Anlagendeckungsgrad I = Eigenkapital / Anlagevermögen x 100

So prüfst du, ob langfristiges Vermögen mit Eigenkapital gedeckt ist.

Prüfungsrelevante Basis

Weitere wichtige Formeln für Industriekaufleute

Diese Formeln tauchen in Eignungstests, Berufsschule und kaufmännischen Aufgaben regelmäßig auf.

Prozentwert

W = (G x p) / 100

Wenn ein Teil vom Ganzen gesucht ist, etwa Rabattbetrag oder Provision.

Grundwert

G = (W x 100) / p

Wenn du aus Teil und Prozentsatz den ursprünglichen Wert ermitteln sollst.

Prozentsatz

p = (W x 100) / G

Nutzt du, wenn der Anteil bekannt ist, aber die Prozentangabe fehlt.

Rabattpreis

Zielpreis = Listenpreis - Rabatt

Oder direkt: Listenpreis x (1 - p/100).

Skonto

Barpreis = Zielpreis - Skonto

Wichtig für Einkaufs- und Verkaufskalkulationen.

Bezugspreis

Bezugspreis = Bareinkaufspreis + Bezugskosten

Hängt häufig an Aufgaben mit Rabatt, Skonto und Transportkosten.

Umsatzsteuer

Brutto = Netto x 1,19 Netto = Brutto / 1,19

Im Test oft als Schnellaufgabe kombiniert mit Rabatt oder Skonto.

Lagerumschlag

Lagerumschlag = Jahresverbrauch / durchschnittlicher Lagerbestand

Zeigt, wie oft das Lager im Jahr erneuert wird.

Kalkulationsfaktor

Kalkulationsfaktor = Listenverkaufspreis / Bezugspreis

Hilft, aus dem Bezugspreis auf den Listenverkaufspreis zu schließen.

Handelsspanne (%)

(Listenverkaufspreis - Bezugspreis) / Listenverkaufspreis x 100

Zeigt die Spanne vom Verkaufspreis in Prozent.

Ø Lagerbestand

(Anfangsbestand + Endbestand) / 2

Basis für Umschlag, Lagerdauer und Lagerzinssatz.

Ø Lagerdauer

360 Tage / Umschlagshäufigkeit

Wie lange Ware durchschnittlich im Lager bleibt.

Meldebestand

(täglicher Verbrauch x Lieferzeit) + Mindestbestand

Bestellgrenze zur Vermeidung von Fehlbeständen.

Lagerzinssatz

Jahreszinssatz x durchschnittliche Lagerdauer / 360

Verknüpft Kapitalbindung mit der Lagerdauer.

Gewinn

Gewinn = Erlös - Kosten

Grundlage für viele Erfolgs- und Rentabilitätskennzahlen.

Deckungsbeitrag

Deckungsbeitrag = Umsatzerlöse - variable Kosten

Wichtig für Break-even und kurzfristige Entscheidungen.

Eigenkapitalrentabilität

Gewinn / Eigenkapital x 100

Rendite auf das eingesetzte Eigenkapital.

Gesamtkapitalrentabilität

(Gewinn + Fremdkapitalzinsen) / Gesamtkapital x 100

Rendite des gesamten eingesetzten Kapitals.

Liquidität 1. Grades

Liquide Mittel / kurzfristige Verbindlichkeiten x 100

Zeigt die sofortige Zahlungsfähigkeit.

Eigenkapitalquote

Eigenkapital / Gesamtkapital x 100

Maß für finanzielle Stabilität und Unabhängigkeit.

Anlagendeckungsgrad I

Eigenkapital / Anlagevermögen x 100

Prüft, ob Anlagevermögen durch Eigenkapital gedeckt ist.

1. Gegeben und gesucht markieren

Unterstreiche Werte und Einheiten. Viele Fehler entstehen nicht beim Rechnen, sondern beim falschen Lesen der Aufgabe.

2. Erst Struktur, dann Zahlen

Stelle die Formel zuerst symbolisch um. Setze Werte erst ein, wenn die richtige Zielformel steht.

3. Ergebnis prüfen

Frage dich: Kann das grob stimmen? Ein Zinssatz von 600 Prozent oder 0,02 Tagen fällt so sofort auf.
